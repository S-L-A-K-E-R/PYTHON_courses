# Advanced Python — Applied Python Lab

**Duration:** 20 hours (10 × 2-hour sessions)  
**Prerequisites:** Previous programming experience, particularly in C  
**Environment:** Python, Google Colab and Jupyter Notebooks

## Objectives

Develop practical Python skills through data analysis, image processing, APIs and scientific computing. Emphasis is placed on independent experimentation and project-based learning.

## Course content

| Sessions | Topics |
|---|---|
| 1 | Python essentials: syntax, collections, functions, strings and files |
| 2–4 | Data analysis: NumPy, pandas, data cleaning and Matplotlib |
| 5 | Object-oriented programming: classes, objects and methods |
| 6–7 | Computer vision: image manipulation and processing with OpenCV |
| 8 | JSON and REST APIs: retrieving and processing external data |
| 9 | SciPy introduction: interpolation and basic signal processing |
| 10 | Mini-project: integration and application of acquired skills |

**Teaching methods:** Short theoretical introductions followed by guided practical labs, independent experimentation and progressive exercises in interactive notebooks.

**Practical work:** Initial two-part Python homework, weekly hands-on labs and a final integration mini-project. Later activities may be adapted to student interests.

Machine learning is taught in a separate course.

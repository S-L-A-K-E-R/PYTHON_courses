# Python - ECE Paris

Welcome to the Python course repository for **ECE Paris Bachelor students**!

Here you'll find course materials, lab exercises, and the syllabus. We mainly use **Google Colab** to write and run Python directly in your browser.

<br>

## Course materials

- **[Courses & Labs](COURSES/)** - Class notebooks and exercises, organized by chapter.
- **[Syllabus](SYLLABUS/syllabus_2.0.md)** - Course topics and learning objectives.

<br>

## How to get started

1. Go to **Courses & Labs** and open the folder for your current chapter.
2. Open the class notebook in Google Colab, then use `File → Save a copy in Drive` to keep your own editable version.
3. Follow the course material and complete the corresponding lab exercises.
4. Submit your completed work using the shared Drive folder indicated in class. **Contact me if you need access.**

<br>

> [!TIP]
> Before submitting a lab, restart your Colab runtime and run all cells from top to bottom to check that everything works.

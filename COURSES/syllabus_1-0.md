These course materials were designed for engineering school, for classes:
- Introduction to **Programming** (and Algorithms)
     - Variables, types and operations
     - Interactive program (user input)
     - Control flow (for, while, if)
     - Functions
     - Collection handlings (-1 for the end): lists, tuples, dictionaries, sets
     - Strings manipulation: slicing, length, functions...

- **Python Essentials**:
     - References and Objects...?
     - Mutable/Immutable objects
     - Iterations: range(), enumerate(), zip()... any(), all()
     - File handling (using Pathlib)
     - Exception raising: try, raise...
     - Built-in functions (get the idea of how python is modular): sorted(), reversed(), min() or max(), sum(), map()...

- **Advanced Python**: 
     - Comprehensions (list, set, dictinary...)
     - Tuples, Dictionaries, Sets, DataClass (not the OOP, just as a structure)
     - Create your library (Packages?)
     - Project Organization
     - Dependencies: pip, VENV, TOML...


- **Specialization coding**: 
     - Introduction to **Data Science**: 
          - NumPy: mathematical arrays, vectors...
          - Pandas: Series & DataFrames
          - Data Cleaning and Quality
          - MatPlotLib: data visualization
          - (...)
     - Scientific Python: SciPy, Integrals (...? Some ideas here that could be linked to engineering degree?)
     - Computer Vision (image representations, OpenCV)
     - Software **GUI**
     - APIs & Structured Data (JSON, REST APIs, GET/POST...)
     - Unit Testing (with PyTest)
     - Code profiling: memory usage, execution time, optimization (algorithm improvement)
     - Asynchronous programming (async, await...)




Following all the classes should give you an autonomous level, high enough for you to code by yourself almost any mid-sized project in Python.
